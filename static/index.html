UDP / File

Chưa chọn file.

Giới hạn qua HTTP: khoảng 82,5 MiB, gồm cả Base64 trong request 110 MiB. Không hỗ trợ gửi file broadcast qua API này.

HTTP chấp nhận yêu cầu chưa có nghĩa người nhận đã nhận được. Theo dõi trạng thái bên dưới; xem terminal nếu worker báo lỗi.

Chưa có lượt truyền file.

Đăng nhập bằng client.py --username … --ui-port …. Khi mất phiên server, khởi động lại client để đăng nhập lại. Hiển thị tối đa 100 tin nhắn và 40 lượt truyền gần nhất.
